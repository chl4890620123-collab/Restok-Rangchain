# Restok Demo Flow

이 문서는 Restok을 로컬에서 시연할 때의 권장 순서입니다. 핵심 메시지는 **AI 재고관리**가 아니라 **URL-first 물품 생애주기 관리**입니다.

## 시연 목표

> 사용자가 시스템에 맞추는 것이 아니라, 시스템을 사용자의 물건 관리 방식에 맞춘다.

시연에서는 물건을 등록하는 것보다 **등록 → 보유 → 처리 선택 → 외부 URL 이동 → 처리 이력 저장 → AI 보조**가 한 흐름으로 이어지는 것을 보여줍니다.

---

## 1. URL 연결 관리

메뉴: `URL 연결 관리`

1. 판매, 기부/나눔, 재활용, 폐기 등 목적을 선택합니다.
2. 사용자가 실제로 쓰는 서비스 이름과 URL을 등록합니다.
3. API가 없는 서비스도 URL만 있으면 연결할 수 있다는 점을 설명합니다.

### 발표 포인트

- URL은 API를 대체하는 기술이 아니라 **가장 범용적인 기본 연결 단위**입니다.
- 자동화 가치가 검증된 서비스만 향후 API/Webhook으로 확장합니다.
- 특정 업체 API에 종속되지 않습니다.

---

## 2. 신규 물품 등록

메뉴: `신규 등록`

### 직접 등록

1. 물품명, 수량, 카테고리, 보관 위치를 입력합니다.
2. 사진/카메라로 실물 이미지를 추가합니다.
3. 유통기한 또는 숙성 기준을 설정합니다.
4. 앞에서 등록한 외부 처리 서비스 또는 직접 URL을 연결합니다.

### 영수증 AI 등록

1. `영수증 AI 분석`을 선택합니다.
2. 영수증 이미지를 업로드합니다.
3. AI가 추출한 품목을 사용자가 검토·수정합니다.
4. 최종 확인한 항목만 일괄 등록합니다.

### 발표 포인트

AI는 서비스의 목적이 아니라 **사용자의 입력 행동을 줄이는 보조 기능**입니다.

---

## 3. 물품 관제 센터

메뉴: `대시보드`

1. 전체 관리 품목 수를 확인합니다.
2. 임박/만료 품목을 필터링합니다.
3. 특정 물품의 `처리 기록` 버튼을 선택합니다.
4. 필요하면 연결된 외부 URL을 별도 버튼으로 바로 열 수 있습니다.

### 발표 포인트

기존 Restok의 재고 관리를 유지하면서, 이제 각 품목의 **다음 행동**까지 관리합니다.

---

## 4. 처리·생애주기 기록

메뉴: `처리·생애주기`

1. 처리할 물품을 선택합니다.
2. 다음 행동을 선택합니다.
   - 사용 완료
   - 판매
   - 기부/나눔
   - 재활용
   - 폐기
   - 수리
   - 이관
3. 처리 수량을 입력합니다.
4. 등록한 외부 서비스 또는 직접 URL을 선택합니다.
5. 필요하면 판매 금액, 폐기 이유, 다음 구매 참고사항 등을 메모합니다.
6. `처리 결과 저장`을 누릅니다.

### 결과

- 보유 수량이 감소합니다.
- 처리 결과가 Lifecycle Event로 보존됩니다.
- 외부 URL과 사용한 서비스가 함께 기록됩니다.
- 단순 삭제와 달리 나중에 소비/폐기 패턴 분석에 활용할 수 있습니다.

---

## 5. 처리 기록 확인

`처리·생애주기` 화면 오른쪽의 처리 기록에서 다음을 확인합니다.

- 어떤 물품을 처리했는지
- 판매/기부/재활용/폐기 중 어떤 행동이었는지
- 몇 개를 처리했는지
- 어떤 URL/서비스를 사용했는지
- 언제 처리했는지

### 발표 포인트

Restok은 **물건이 사라지는 순간 데이터를 삭제하지 않습니다.**
물건의 마지막 행동을 기록해 다음 구매와 소비 판단을 위한 데이터로 바꿉니다.

---

## 6. AI 보조

메뉴: `AI 보조`

예시 질문:

- "유통기한이 가까운 물건부터 알려줘"
- "최근에 반복해서 처리한 물건이 있어?"
- "지금 보유 중인 물건 중 먼저 사용해야 할 것은 뭐야?"
- "내 최근 처리 이력을 고려하면 어떤 물건을 덜 사는 게 좋을까?"

### 발표 포인트

AI는 현재 보유 물품과 최근 Lifecycle 이력을 바탕으로 답변합니다.
향후에는 공공 폐기/재활용 정보 RAG를 별도 지식 계층으로 연결할 수 있습니다.

---

# 3분 시연 버전

1. URL 연결 관리에서 판매/기부 URL 등록 - 25초
2. 영수증 또는 직접 입력으로 물품 등록 - 35초
3. 대시보드에서 임박 물품 선택 - 25초
4. 처리·생애주기에서 `판매` 또는 `기부` 처리 - 45초
5. 처리 기록이 남은 것 확인 - 25초
6. AI에게 현재 재고/최근 처리 기반 질문 - 25초

핵심 마무리 문장:

> Restok은 물건을 저장하는 앱이 아니라, 물건이 들어온 순간부터 나가는 순간까지 사용자가 원하는 방식으로 관리하고 그 결과를 다시 데이터로 남기는 플랫폼입니다.
